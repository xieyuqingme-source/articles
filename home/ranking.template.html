备份与使用说明

修改自动保存在当前浏览器中。清理网站数据或更换设备会丢失本地存档，重要排行请导出 JSON 备份。多标签页以最后保存为准。

键盘：Tab 选中卡片，Enter 打开编辑，选择等级后保存；也可用「向前 / 向后」调整同级顺序。触屏：点卡片选级，或按住右上角拖动柄移动。默认进入展示模式，保留排行榜和待选区，点「编辑 / 退出展示」或按 Esc 编辑。

PNG 只导出标题、所有等级和已归级项目，不包含待选区与编辑按钮；长名称与长列表自动换行。特别长的榜单会自动降低输出倍率，超过安全尺寸会提示拆分。
