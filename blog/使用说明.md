- 中文稿继续放在“中文文章”，英文稿继续放在“English Articles”；图片和附件目录不变。
- 文章继续使用 `YYYY-MM-DD-标题.md` 文件名与 `# 标题`。更新旧文时保留文件名，博客网址随之保持稳定。
- 博客显示原发表日期，按发表日期倒序排列；原有文件名和文章网址保持不变。特殊日期依据存放在 `blog/publication-dates.json`，不会重新加进正文。年月精度照实显示，未知日期标为“发表时间待确认”；转载页日期与首发日期分别说明。
- 首页和语言栏目自动收录两个文章目录中的 `.md` 文件。“关于我”从 README 生成；README 的 GitHub 文章索引仍按原 SOP 更新。
- 2026-10-11 作者介绍已按用户原文更新：主页正文在 `home/index.template.html`，“关于我”正文来自 README 开头，站点描述在 `blog/config.json`。邮箱 `xieyuqing.me@gmail.com` 已获准公开，并在主页和关于页提供 `mailto:`；公众号只显示“谢雨聊”，不添加猜测的链接或二维码。主页大标题为同字号的“谢雨卿”（无标点），保留英文副标题“Xie Yuqing · Carl”；中文简介按用户指定的五项内容分行，已删除“大家可以通过公众号或邮箱联系我。”，正文不重复姓名。右侧文章入口卡片标题为“我的文章”，小字使用用户指定的完整原句“年寿有时而尽，荣乐止乎其身，二者必至于常期，未若文章之无穷。”，沿用自然换行样式、计数与文章栏目链接。
- 文章栏目 `/articles/` 的大标题与中英文首发说明由 `blog/config.json` 中 `article_heading`、`article_description`、`article_english_description` 管理，与作者简介的 `description` 和 README 分开；列表标题及同区eyebrow统一显示“文章”，保留原归档锚点和分页筛选。
- 图片、附件或文章链接缺失时，构建会报错，避免发布带有失效链接的新版本。
- 支持 Obsidian 的 `[^注释编号]` 脚注及对应定义，表格中的 `<br>` 也会显示为换行。其他原始 HTML 仍按文字显示。

## 复制到公众号

打开博客文章 → 滚动到正文末尾，点击“复制到公众号” → 在公众号正文中用普通 `Ctrl+V` 粘贴 → 单独填写标题、作者和封面 → 保存草稿并在手机上预览。

- 专用排版为白底、16px 正文、两倍行距；保留原文、标题层级、图片顺序和表格。博客阅读页使用站点主题，公众号预览保持白底。
- 旧草稿先在正文区域全选并替换，不要叠加粘贴；不用“粘贴为纯文本”。
- 可展开“公众号排版预览”查看白底版本；自动复制失败时，只选中该预览里的正文手动复制。
- 图片引用已发布博客的完整网址，粘贴后仍需核对图片是否成功保存、表格是否适合手机阅读。这一步只复制内容，不会替你发表。

`blog/config.json` 管理标题和简介，`blog/style.css` 管理外观，`scripts/build_site.py` 统一生成并检查主页和文章网页（内部复用 `scripts/build_blog.py`），`.github/workflows/pages.yml` 自动发布。现有文章、图片和 README 是内容来源。

`blog/wechat-copy.js` 管理公众号富文本复制；专用排版在生成器的 `WechatContent` 中设置。日常新增文章无需修改这些文件。

`_site_unified` 是统一生成的网页，`.blog-deps` 是本地依赖，`.local-checks` 是交互检查记录；均被忽略，不提交。工作流只上传 `_site_unified`。旧 `_site` 和独立的“个人主页发布”目录此次保留，供对照，不再作为新工作流输出。统一构建不会删除已有文件；CI 从新的 checkout 构建。如果以后删除公开文章，本地旧输出应另行核对，不能只以旧预览判断线上是否已删除。

供 AI 维护：先核对原 SOP；保持现有文章目录、文件名和图片字节，不把原 Obsidian 笔记或整个附件库导出。博客生成器只读取公开稿目录；链接转换只发生在生成网页时，不改写 Markdown 源文件。需要改外观时修改模板或样式，不要重写文章。

## 本地预览与阅读功能

构建完成后，在本目录运行：

```text
python scripts/preview_site.py
```

打开 <http://127.0.0.1:8767/> 查看主页，<http://127.0.0.1:8767/articles/> 查看文章；终端按 `Ctrl+C` 停止服务。服务只读取 `_site_unified`，仅监听本机，禁止列目录及隐藏路径。端口占用时加 `--port 8768`，主页和文章使用同一个新端口。

- 默认使用深蓝与青绿主题，右上角可以切换明暗模式。主题偏好保存在当前浏览器本地；浅色模式使用暖纸底色。两种模式均可阅读和搜索。
- 顶部“个人主页”返回根站，“文章首页”回到文章栏目，旧文章网址保持不变。生产站链接分别为 `/` 和 `/articles/index.html`。
- 本地主页、文章和“关于我”由同一个预览服务提供，双向导航无需跨端口转换。主页样式与脚本在 `home/assets`，模板在 `home/index.template.html`。
- 首页和语言栏目提供主题、发表年份筛选及标题与摘要搜索，每页12篇。切换筛选时回到第一页；链接保留当前条件和页码，方便返回。清除搜索和筛选即可恢复全部文章；键盘按 `/` 可进入搜索。
- 分页区可输入页码并点击“跳转”或按回车；页码必须是当前筛选结果范围内的正整数。输入无效时显示提示并保留当前页；只有一页或没有结果时隐藏分页区，手机上跳转控件独占一行。
- 阅读页显示预计阅读时间、文章目录、阅读进度以及相邻文章入口。长表格在手机上可以横向滚动；配图自适应屏幕宽度。
- 页尾可订阅 RSS，地址为 <https://xieyuqingme-source.github.io/articles/feed.xml>，每次构建自动更新。
- `blog/site.js` 管理明暗切换、搜索、主题筛选和阅读交互；正文仍由公开 Markdown 生成。禁用 JavaScript 后仍可浏览文章和使用目录链接。

本地生成和预览不会触发 GitHub 更新。仓库切换和首次统一发布已由用户手动完成；AI默认只整理本地文件，用户在GitHub Desktop审阅、Commit和Push后才会更新网站。不要在旧主页备份目录提交或推送日常修改。Waline继续默认关闭。
